# YPN USA — AWS Amplify deployment

Deploy branch `rebuild/ypnus-node-commercial` as a preview before changing DNS.

## Amplify settings

- Framework: Next.js SSR
- Node.js: 22
- Build specification: repository `amplify.yml`
- Build branch: `rebuild/ypnus-node-commercial`
- Production branch after approval: `main`

## Required environment variables

Configure these in Amplify Hosting > App settings > Environment variables.

- `NEXT_PUBLIC_SITE_URL` — preview URL first; later `https://app.ypnus.com`
- `NEXT_PUBLIC_MARKETING_SITE_URL` — preview URL first; later `https://ypnus.com`
- `SESSION_SECRET` — strong random secret; never commit it
- `YPNUS_SSO_SHARED_SECRET` — required only while legacy SSO remains
- `ANTHROPIC_API_KEY` — required for the AI assistant
- `STRIPE_CUSTOMER_PORTAL_URL` — existing Stripe customer portal link
- `NEXT_PUBLIC_STRIPE_PAYMENT_LINK_GROWTH` — existing Growth Payment Link
- `NEXT_PUBLIC_STRIPE_PAYMENT_LINK_PRO` — existing Pro Payment Link
- `NEXT_PUBLIC_STRIPE_PAYMENT_LINK_ELITE` — existing Elite Payment Link

Also copy every production integration variable documented in `.env.example` that is needed for email, SMS, calendar, database, and webhook fulfillment. Do not invent replacements.

## Preview acceptance test

1. Homepage, pricing, features, blog, robots.txt, sitemap.xml and local sitemap return 200.
2. ZIP check gives a real response.
3. Internal `/signup` records a test lead with consent.
4. Login reaches the dashboard using a test account.
5. Growth, Pro and Elite open the correct Stripe test checkout with the selected ZIP.
6. Fulfillment webhook provisions the matching plan and ZIP.
7. Existing hero video renders correctly on mobile and desktop.
8. No production DNS is changed until all checks pass.

## DNS cutover

After preview approval, add `ypnus.com` and `www.ypnus.com` as Amplify custom domains. Use the DNS validation and routing records generated by Amplify. Keep the old DNS records until Amplify reports the domain as available and the production branch has passed the acceptance test.
